# Project Carousel & Achievement Badges Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transform the project section into a clean, minimalist horizontal snap-scroll carousel and replace the static credential text with structured arcade achievement cards.

**Architecture:** Utilize native CSS scroll-snap (`scroll-snap-type: x mandatory`) and vanilla DOM APIs to create a 60fps horizontal carousel without external dependencies. Build a 3-column responsive achievement card matrix replacing the plain text `.creds` footer.

**Tech Stack:** Native HTML5, CSS3 Modern Features (Scroll Snap, CSS Variables), Vanilla JavaScript (Web Audio API, DOM APIs), Google Fonts (Press Start 2P, Geist Mono, Geist).

**Spec:** [docs/superpowers/specs/2026-11-03-project-carousel-and-achievements-design.md](file:///d:/portofolio-yuzu/docs/superpowers/specs/2026-11-03-project-carousel-and-achievements-design.md)

## Global Constraints

- Zero third-party slider libraries (No Swiper, Slick, or external packages) in accordance with Ponytail guidelines.
- Responsive reflow: Desktop displays ~2 cards with 3rd card peek; Mobile (≤720px) displays 1 card (85vw) with clean horizontal swipe.
- All existing project dialog modal features, filter tabs, and chiptune audio triggers must remain fully intact.
- Target files: `D:/portofolio-yuzu/mockup-8bit-arcade.html` and synchronized to `C:/Users/ASUS/.opencode/plan/mockup-8bit-arcade.html`.

## Review Focus

1. **Horizontal scroll containment:** Verify the track scrolls smoothly horizontally without causing unwanted body-level horizontal overflow on mobile viewports.
2. **Filter tab synchronization:** When switching categories (`INTERNAL`, `SHIPPED`, `ARCHIVE`), the carousel track must reset its scroll offset to `0` and update the active counter.
3. **Modal trigger reliability:** Clicking any card inside the carousel or clicking a stage pill from the Tech Tree inspector must open the correct project dialog without layout jank.
4. **Keyboard accessibility:** Left/Right arrow keys and Tab navigation must cleanly navigate through cards and inside the opened modal.
5. **Reduced motion compliance:** `prefers-reduced-motion` must disable smooth scrolling and stepped pulse effects.
