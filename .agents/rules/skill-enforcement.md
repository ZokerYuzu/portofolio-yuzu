# Skill Enforcement Rule

Pada setiap request dari user di workspace ini, agen WAJIB selalu mengacu dan mematuhi aturan dalam file root [AGENTS.md](file:///d:/portofolio-yuzu/AGENTS.md) serta skill di [`.agents/skills/`](file:///d:/portofolio-yuzu/.agents/skills):
1. **Ponytail**: Hindari over-engineering, utamakan native platform dan kesederhanaan (YAGNI).
2. **Anti-Slop**: Hindari desain klise AI generik, komentar redundan, dan filler text palsu.
3. **21st & Shadcn**: Gunakan standar komponen UI yang konsisten dengan `components.json` dan Tailwind v4.
4. **Respon Efisien**: Berikan jawaban langsung ke inti teknis secara padat dan akurat.
